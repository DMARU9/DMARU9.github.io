## はじめに

「自分の Web サイトを持ちたい」「作ったページをインターネットに公開してみたい」

そんなふうに思ったことはありませんか？ この記事では、**難しいサーバーの設定やお金をかけずに**、自分だけの Web サイトを公開する方法を紹介します。

使うサービスは **GitHub Pages**。なんと **完全無料** でサイトを公開できます。

---

## GitHub Pages とは？

### GitHub って何？

まず、「GitHub（ギットハブ）」を知らない方のために簡単に説明します。

GitHub は、世界中のプログラマーが使っている **ファイルの保管・共有サービス** です。

- 作ったファイルをクラウド上に保存できる
- 世界中の人と共有・協力できる
- **無料で使い始められる**

### GitHub Pages とは？

GitHub Pages は、GitHub に保存したファイルをそのまま **Web サイトとして公開できる無料サービス** です。

- 難しいサーバー設定は一切不要
- ファイルを保存するだけで公開できる
- **自分だけの専用 URL が手に入る**

### 3 つのメリット

1. **完全無料** — サーバー代も公開費用も 0 円
2. **ずっと公開され続ける** — 自分で削除しない限り、サイトはずっとインターネット上に存在
3. **自分だけの URL** — `https://（ユーザー名）.github.io/` というアドレスが手に入る

### こんなサイトが作れる

- 自己紹介サイト — 就職・転職のポートフォリオに
- 学習ノートの公開 — 勉強した内容をまとめて発信
- サークルや団体のサイト — イベント告知・メンバー紹介
- プロジェクト集 — 写真や作品を並べたギャラリー

## 準備するもの

必要なのはたった一つ、**GitHub のアカウント（無料）** だけです。

特別なソフトのインストールは不要です。ブラウザだけで全ての作業が完了します。

### アカウントの作り方

[GitHub のサインアップページ](https://github.com/signup) からメールアドレスや Google アカウントを使って簡単に登録できます。すでにアカウントをお持ちの方はそのまま次のステップへ進んでください。

### ユーザー名は慎重に決めよう

GitHub Pages のサイトアドレスは次の形式になります：

```
https://（ユーザー名）.github.io/
```

登録時のユーザー名がそのまま URL に使われるため、**あとから変更すると URL も変わってしまう** ので、最初に慎重に決めるのがおすすめです。

- ✅ 英数字とハイフン（`-`）が使える
- ❌ スペースや記号は使えない

### STEP 1: リポジトリを作る

「リポジトリ」とは、ファイルをまとめる専用のフォルダのことです。まずはこのフォルダを作ります。

#### 手順

1. GitHub にログインし、右上の [+] ボタンをクリック → **New repository** を選択

> ![GitHub の「+」ボタン → New repository メニュー](/images/blog/github-pages-intro/New_repository.webp)

2. **Repository name** に `（ユーザー名）.github.io` と入力する  
   例：ユーザー名が `DMARU9` なら、`DMARU9.github.io`
3. **Public**（公開）が選ばれていることを確認する
4. **Create repository** ボタンをクリック

> ![リポジトリ作成](/images/blog/github-pages-intro/create_repository.webp)

#### リポジトリ名のルール

`（ユーザー名）.github.io` という名前は GitHub の特別なルールです。この名前のリポジトリがそのまま **あなたのサイトのトップページ** になります。

| ユーザー名 | リポジトリ名 | 公開される URL |
|---|---|---|
| `DMARU9` | `DMARU9.github.io` | `https://DMARU9.github.io/` |
| `taro123` | `taro123.github.io` | `https://taro123.github.io/` |

> **⚠️ 注意**: 無料アカウント（GitHub Free）で GitHub Pages を使う場合、リポジトリは **Public（公開）** にする必要があります。  
> リポジトリ内のすべてのファイルが誰でも閲覧できる状態になるため、**パスワードや個人情報など、他人に見られたくない情報は置かない** ようにしましょう。

---

### STEP 2: index.html を作る

リポジトリの中に HTML ファイルを作ります。このファイルが Web サイトの「中身」になります。

#### 手順

1. リポジトリのページで **Add file** → **Create new file** をクリック

> ![Add file ボタン](/images/blog/github-pages-intro/add_file.webp)

2. ファイル名の欄に `index.html` と入力する

> ![index_html](/images/blog/github-pages-intro/index_html.webp)


#### なぜ「index.html」という名前なのか？

Web サーバーには **「フォルダを開いたとき、まず `index.html` を表示する」** というルールがあります。

- `https://example.com/` にアクセス → `index.html` が表示される
- `https://example.com/profile/` にアクセス → `profile/index.html` が表示される

このルールのおかげで、URL に `index.html` と書かなくてもページが表示されるのです。

#### 中身を書いてみよう

ファイル名を入力したら、エディターの部分に以下の HTML をコピー＆ペーストしてみましょう。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>○○○のホームページ</title>
</head>
<body>
  <h1>こんにちは！</h1>
  <p>○○○のホームページへようこそ。</p>
  <p>趣味：読書、カメラ、旅行</p>
  <p>少しずつ更新していきます。</p>
</body>
</html>
```


#### ファイルを保存する

1. ページの右上にある **Commit changes...** ボタンをクリック
2. ダイアログが表示されたら、**Commit message** の欄にメッセージを入力（例：「最初のページを作成」）
3. **Commit changes** ボタンをクリック


---

### STEP 3: 公開設定を確認する

デフォルトで公開スイッチは入っているはずですが、念のため確認しましょう。

#### 手順

1. リポジトリページ上部の **Settings** タブをクリック
2. 左のメニューから **Pages** を選択

> ![pages](/images/blog/github-pages-intro/pages.webp)

3. 「Your site is live at `https://（ユーザー名）.github.io/`」と表示されていれば OK！

> ![visit_site](/images/blog/github-pages-intro/visit_site.webp)

表示されない場合は 2〜3 分待ってからページを再読み込みしてみてください。

---

## 公開完了！URL を確認しよう

以下の URL にアクセスすると、先ほど入力した `index.html` の内容が Web ページとして表示されます。

```
https://（ユーザー名）.github.io/
```

スマートフォンからも見ることができます。表示されない場合は、ユーザー名を間違えていないか確認してみてください。

おめでとうございます！**これであなただけの Web サイトが公開できました！** 🎉

---

## サイトを更新するには

サイトの内容を変えたいときは、ファイルを編集するだけです。

#### 手順

1. リポジトリで編集したいファイル（例：`index.html`）を選択
2. 右上の鉛筆アイコン（✏️）をクリック
3. 内容を書き換える
4. **Commit changes...** を押して保存

2〜3 分ほどで変更が Web サイトに反映されます。

---

## プロジェクトを追加するには

新しいプロジェクト（作品）を追加するときも、同じリポジトリの中にフォルダを作るだけです。

例えば、次のような構成にできます：

```
（ユーザー名）.github.io/
├── index.html         →  /                     （トップページ）
├── profile/
│   └── index.html    →  /profile/              （プロフィール）
├── portfolio/
│   └── index.html    →  /portfolio/            （作品集）
└── game/
    └── index.html    →  /game/                 （ゲーム）
```

フォルダ名がそのまま URL のパスになります。

## まとめ

GitHub Pages でできることのおさらいです。

**✅ 無料で Web サイトを公開できる**  
**✅ 自分だけの URL（`https://（ユーザー名）.github.io/`）が手に入る**

公開の 3 ステップ：

1. `（ユーザー名）.github.io` という名前のリポジトリを作る
2. `index.html` を追加して保存する
3. `https://（ユーザー名）.github.io/` にアクセスして確認する

あとは自由にカスタマイズしたり、新しいページを追加したりして、自分だけのサイトを育てていってください。
